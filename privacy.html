EJD File Srv Backup

Privacy policy

Last updated: September 27, 2026.

This application is used only by its operator to back up files from a personal file server. It does not accept public accounts.

Google Drive access

The application requests Google Drive drive.file access. It uses that access to create, read, list, and remove the backup files it creates in the operator's Google Drive. It does not request access to unrelated Drive files.

Backup data and credentials

Files are encrypted on the operator's server before upload. Google Drive stores the encrypted backup repository. The application's Google authorization credentials and the backup encryption password are stored on systems controlled by the operator.

Sharing and retention

The application does not sell or share data with advertisers or other users. Google processes the stored backup files under the operator's Google Drive account. Old backup snapshots are removed according to the operator's backup retention settings.

Control

The operator can revoke the application's Google Drive access from Google Account settings and delete its backup files from Google Drive. For questions, use the support email shown on the Google authorization screen.
